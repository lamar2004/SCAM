Proyecto SCAM  

Introducción 

SCAM es un proyecto interdisciplinario que integra Ingeniería en Sistemas Computacionales e Ingeniería en Mecatrónica, con proyección hacia la rama de Ingeniería Logística. Su objetivo es desarrollar soluciones automatizadas con enfoque industrial, combinando hardware, software y gestión para optimizar procesos de secado y ventilación.

¿En qué consiste SCAM?

SCAM (System for Climatic Administration & Mechatronics) es un proyecto interdisciplinario que busca automatizar procesos de secado y gestión de ventilación en entornos industriales simulados.

Integra Ingeniería en Sistemas Computacionales, Ingeniería en Mecatrónica y Ingeniería Logística, con el objetivo de combinar hardware, software y administración para optimizar el control climático en bodegas o espacios de almacenamiento.

Sistemas principales

* Rack de Secado Inteligente (La Carga)
  * Estructura tipo túnel con perfil de aluminio V-Slot 2020.
  * Rack móvil con motor Nema 17 y ventiladores de extracción.
  * Sensores DHT22 para detectar humedad y activar el proceso de secado.
  * Dashboard en React para visualizar progreso y estado.
* Gestión de Ventilación y Humedad (El Entorno)
  * Rejillas automatizadas con servomotores SG90.
  * Ventiladores de PC controlados por PWM para extracción/inyección de aire.
  * Célula Peltier para simular deshumidificación.
  * Escenarios críticos como lluvia, con respuesta automática en tiempo real.

Módulos  a desarrollar

Rack de Secado Inteligente (La Carga) – Ingeniería en Mecatrónica

* Diseño y construcción de la estructura tipo túnel.
* Integración de motores, guías lineales y ventiladores.
* Implementación de sensores de humedad y control automático.

Gestión de Ventilación y Humedad (El Entorno) – Ingeniería en Mecatrónica

* Desarrollo de compuertas automatizadas con servomotores.
* Control de ventiladores de extracción/inyección mediante PWM.
* Simulación de deshumidificación con célula Peltier.

Plataforma Web y Móvil – Ingeniería en Sistemas Computacionales

* Dashboard en React para monitoreo en tiempo real.
* Aplicación móvil para control remoto.
* Submódulos: control de versiones, pruebas, despliegue y mantenimiento.
